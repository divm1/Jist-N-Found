# Jist-N-Found
a demo lost &amp; found board for college campus. To be presented in JIST Makerspace's Noboshristi 1.0 2026

Features
Report a lost or found item through a simple form
Browse all reported items in one place
Search by name or location
Filter by category and by lost/found status
Mark an item as claimed once it's returned
Data persists in the browser via localStorage
Tech Stack
HTML5
CSS3 (no frameworks)
Vanilla JavaScript
Browser localStorage for data persistence (no database/server)
Getting Started
Clone or download this repository
Open index.html in any browser — no build step or server needed
bash
git clone <your-repo-url>
cd lost-and-found
open index.html
Project Structure
lost-and-found/
├── index.html      # Home page
├── report.html     # Report an item
├── browse.html     # Browse & search items
├── style.css       # Styling
├── script.js       # Form handling, search/filter logic, localStorage
